# Contact — `/contact`

## Objectif

Simplifier la prise de contact et obtenir les informations nécessaires pour qualifier la demande.

Le formulaire doit permettre de décrire simplement un diagnostic structurel, un projet de travaux ou un désordre observé : plancher qui bouge ou qui vibre, poutre qui fléchit, fissures, charpente qui se déforme, bois dégradé ou question sur un mur porteur. Ces exemples aident les visiteurs à formuler leur demande ; ils ne constituent pas un diagnostic.

## Hero

### Parlons de votre projet.

Décrivez votre besoin en quelques mots. Plus nous comprenons le contexte, plus nous pouvons vous orienter vers la mission adaptée.

## Vous ne savez pas encore quelle étude prévoir ?

Indiquez simplement l'état d'avancement du projet ou ce que vous observez sur l'existant. Nous vous aiderons à préciser votre demande.

## Formulaire

| Champ | Statut / valeurs |
| --- | --- |
| Prénom et nom | Obligatoire |
| Société / organisation | Facultatif |
| E-mail | Obligatoire |
| Téléphone | Facultatif |
| Commune ou localisation du projet | Obligatoire |
| Votre profil | Maître d'ouvrage, architecte, maître d'œuvre, entreprise, particulier / porteur de projet, autre                      |
| Nature du besoin | Obligatoire : conception, exécution, diagnostic avec recommandations, constat visuel, besoin à préciser |
| Type de projet | Construction, rénovation, extension, transformation, autre |
| État d'avancement | Réflexion, conception, consultation, travaux, ouvrage existant, autre |
| Description du projet ou de la demande | Obligatoire |
| Détails utiles selon le besoin | Désordres observés, éléments concernés (plancher, poutre, solives, charpente, mur), date d'apparition si connue ; travaux envisagés et charges ajoutées si connues |
| Documents disponibles | Plans, photos, rapport existant, autre ; pièces jointes facultatives si disponibles |
| Information sur les données personnelles | Afficher à proximité du formulaire un lien vers `/politique-de-confidentialite`. Ne pas présenter le traitement nécessaire à la réponse comme un consentement obligatoire. |

**Bouton :** `Envoyer ma demande`

Les informations transmises servent uniquement à étudier votre demande et à vous recontacter.
